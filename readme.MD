## Studee populator script

This script is designed to take in a textfile written in a certain format, clean it by separating it out into different course units, and then add it to a Firebase database.

## Setup your environment

Use Python 3.11. The dependency update uses Firebase Admin 7.7.0 and
Firestore 2.34.1 with their compatible current Google SDK, gRPC 1.84.0 and
protobuf 7.36.2. The script's certificate initialization and
`course_outline/unilag/engineering` collection path are unchanged. Installing
dependencies does not connect to Firebase or populate data.

`Pipfile.lock` is generated by Pipenv, including real distribution hashes;
`requirements.txt` is exported from that lock with `pipenv requirements`.
After editing `Pipfile`, run `pipenv lock` and regenerate the export rather
than editing lock entries or hashes manually.

Safe checks are compilation, dependency imports without initializing an app,
and `python read.py example.txt`. Do not run `populator.py` against a real
configuration during validation. Hosted validation constructs only a Firestore
document reference with anonymous credentials; it performs no database calls.

Installer limitation (2026-10-22): current pip 26.2.2 and Pipenv 2026.10.2's
patched pip still bundle urllib3 2.7.0, with advisories fixed in 2.8.0.
The application's urllib3 pin does not patch these private installer copies.
Hosted artifacts inventory application and installer dependencies separately;
a patched installer release is still needed. No all-tooling-clean claim is made.
